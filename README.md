# 🏛️ Ηλεκτρονικό Πρωτόκολλο Εγγράφων

Μια σύγχρονη, αξιόπιστη και ολοκληρωμένη εφαρμογή διαχείρισης πρωτοκόλλου εγγράφων (Εισερχομένων & Εξερχομένων) για δημόσιες υπηρεσίες, γραφεία και επιχειρήσεις. Αναπτύχθηκε με **Python 3**, **PyQt6**, **Qt Designer** και τοπική βάση δεδομένων **SQLite**.

## ✨ Κύρια Χαρακτηριστικά

- **📋 Πλήρης Διαχείριση Πρωτοκόλλου:**
  - Κατηγοριοποίηση: *ΕΙΣΕΡΧΟΜΕΝΟ*, *ΕΞΕΡΧΟΜΕΝΟ*, *ΜΕ ΑΠΑΝΤΗΣΗ*.
  - Αυτόματη σειριακή αρίθμηση ανά έτος (κάθε νέο έτος ξεκινά αυτόματα από το **#1**).
  - Δυναμικό κλείδωμα και ξεκλείδωμα σχετικών πεδίων ανάλογα με την κατηγορία εγγράφου.
  - Ζωντανό ρολόι με πλήρη ελληνική μορφή ημέρας και μήνα.

- **🔒 Προστασία Δεδομένων & Ακούσιας Τροποποίησης:**
  - **Λειτουργία Προβολής (Read-Only):** Οι ήδη καταχωρημένες εγγραφές προστατεύονται από τυχαίες αλλαγές.
  - **Κουμπί «✏️ Επεξεργασία»:** Απαιτείται συνειδητή επιλογή για τροποποίηση εγγραφής με δυνατότητα ακύρωσης («❌ Ακύρωση»).
  - **Προειδοποίηση Τροποποίησης:** Διάλογος επιβεβαίωσης πριν από την αποθήκευση αλλαγών σε υπάρχον πρωτόκολλο.
  - **Unsaved Changes Guard:** Αυτόματος έλεγχος για μη αποθηκευμένες αλλαγές κατά την πλοήγηση, αλλαγή έτους ή έξοδο.

- **🔍 Σύνθετη Πολυκριτηριακή Αναζήτηση:**
  - Αυτόνομο παράθυρο αναζήτησης με 4 υπομενού (Εισερχόμενα / Εξερχόμενα με ημερομηνία πρωτοκόλλησης ή ημερομηνία εγγράφου).
  - Φιλτράρισμα βάσει εύρους ημερομηνιών, έτους, υπηρεσίας, είδους εγγράφου και λέξεων-κλειδιών στην περίληψη.
  - Άμεση μετάβαση στην κύρια καρτέλα με **διπλό κλικ** στο αποτέλεσμα.
  - Δυνατότητα άμεσης εξαγωγής αποτελεσμάτων σε αρχείο **CSV**.

- **🛡️ Αυτόματα Migrations & Ασφάλεια Βάσης:**
  - **Schema Versioning (`PRAGMA user_version`):** Αυτόματος έλεγχος και αναβάθμιση δομής χωρίς απώλεια δεδομένων.
  - **Pre-Migration Safety Backups:** Αυτόματη λήψη αντιγράφου ασφαλείας στον φάκελο `backups/` πριν από κάθε αλλαγή δομής.
  - Υποστήριξη εξαγωγής σε CSV, χειροκίνητου backup και πλήρους επαναφοράς (restore).
  - Ασφαλής επιλογή επαναφοράς/διαγραφής με υποχρεωτική πληκτρολόγηση της λέξης `ΔΙΑΓΡΑΦΗ`.

- **🔄 Αυτόματες Ενημερώσεις (Auto-Update):**
  - Αυτόματος αθόρυβος έλεγχος για νέες εκδόσεις στο παρασκήνιο μέσω του **GitHub Releases API**.
  - Δυνατότητα χειροκίνητου ελέγχου από το μενού *Βοήθεια ➔ 🔄 Έλεγχος Ενημερώσεων...*.
  - Αυτόματη λήψη του νέου Inno Setup installer και σιωπηλή εγκατάσταση (`/SILENT`).

- **📦 Έτοιμος Εγκαταστάτης Windows (Inno Setup Installer):**
  - Δημιουργία εκτελέσιμου `.exe` χωρίς ανάγκη εγκατάστασης Python στον υπολογιστή του τελικού χρήστη.
  - Αυτόματο workflow στο GitHub Actions για μεταγλώττιση (PyInstaller) και δημιουργία installer σε κάθε νέο Release.

## 🛠️ Τεχνολογικό Stack

- **Γλώσσα Προγραμματισμού:** Python 3.13
- **Γραφική Διεπαφή (GUI):** PyQt6 & Qt Designer

- **Συσκευασία & Μεταγλώττιση:** PyInstaller
- **Δημιουργία Εγκαταστάτη:** Inno Setup 6
- **CI / CD & Διανομή:** GitHub Actions & GitHub Releases

Για να χρησιμοποιήσετε την εφαρμογή, **ΔΕΝ χρειάζεται Python, γραμμή εντολών ή καμία εξωτερική ρύθμιση**.

   - Περιλαμβάνει σύστημα αυτόματης απεγκατάστασης (Uninstall) από τις Ρυθμίσεις των Windows.
   - Ελέγχει και λαμβάνει αυτόματα μελλοντικές ενημερώσεις!

## 📦 Δημιουργία Νέας Έκδοσης (Release & Installer)

Η εφαρμογή περιλαμβάνει έτοιμο GitHub Actions workflow ([`.github/workflows/release.yml`](.github/workflows/release.yml)).

### Αυτόματη Δημιουργία μέσω Git Tag:
1. Ενημερώστε την έκδοση στο [`version.py`](version.py) (π.χ. `__version__ = "1.0.1"`).
2. Δημιουργήστε και στείλτε ένα Git tag:
   ```bash
   git tag v1.0.1
   git push origin v1.0.1
   ```
3. Το GitHub Actions θα αναλάβει αυτόματα:
   - Τη μεταγλώττιση σε αυτόνομο `.exe` (PyInstaller).
   - Τη δημιουργία του Windows Installer (`Protocol_Setup_v1.0.1.exe`).
   - Τη δημοσίευση νέου GitHub Release με το έτοιμο αρχείο εγκατάστασης!

### Τοπική Μεταγλώττιση (Προαιρετικά):
Αν επιθυμείτε να δοκιμάσετε τη μεταγλώττιση τοπικά στον υπολογιστή σας:
```bash
build.bat
```
Το εκτελέσιμο θα δημιουργηθεί στον φάκελο `dist\Protokollo\Protokollo.exe`.
